# Pokemon Go x Android Macro
Pokemon GO macros using Android Macro

## Why?

There are many repetitive actions that can be automated using macros. Some macros can be done with basic macro apps like [Auto Clicker](https://play.google.com/store/apps/details?id=autoclicker.clicker.autoclickerapp.autoclickerforgames&hl=en_US). But there comes some limitations that requires some logic. With [Android Macro](https://play.google.com/store/apps/details?id=com.androidmacro&hl=en_US), some more complex macros can be performed.

This is my repository to distrubute my created macros

## Requirements

- Pokemon Go (Google Play Store or Samsung version)
- [Android Macro](https://play.google.com/store/apps/details?id=com.androidmacro&hl=en_US)

## FAQ

### Will the macro work on my phone?

Most likely. I'm using a Pixel 11 Pro XL and also have some other Samsung and Pixel phones to test. I play with the English language in Pokemon Go. I plan work make these macro with other slab phones. No tablets or folding phones for now.

Also I will update these macros as Pokemon Go UI changes in the future.

To report issues or express interest on supporting your phone, [submit a ticket](https://github.com/MeGotsThis/android-macro-pokemon-go/issues/new).
